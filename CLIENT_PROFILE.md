# Профили клиентов и скидки

## Сценарий клиента
- На первом открытии Mini App нет обязательной анкеты. Клиент может сразу пользоваться каталогом.
- Нижний пункт «Профиль» открывает компактную карточку «Данные для заявок». Кнопка разворачивает имя/ФИО, телефон, тип партнёра и необязательное название организации.
- Поля профиля сохраняются по аутентифицированному Telegram ID в существующем файле данных заявок. Процент скидки нельзя изменить из клиентского запроса.
- Если клиент подал заявку до заполнения профиля, её контакты автоматически создают профиль.
- При повторной заявке из заполненного профиля форма начинает с выбора локации: 2 шага («Локация» и «Проверка»). Для потенциального партнёра без организации запрашивается недостающий реквизит.
- Названия заявок в интерфейсе содержат название локации, а не служебный номер. Существующая обработка заявок и дополнений осталась без изменений.
- Активная заявка показывает получено/в работе/решено; линия плавно заполняется до текущего этапа и активная иконка кратко подсвечивается.
- Широкая плашка «Бонусы» показывает приглашение. В её деталях доступная скидка на следующую оплату или «У Вас нет скидок». Персональной ссылкой можно поделиться. В этом же разделе клиент запрашивает использование скидки и видит решение администратора.

## Сценарий администратора
- В админской вкладке новый раздел «Профили клиентов» с поиском по имени, телефону и Telegram ID.
- Фильтры: все, действующие, потенциальные.
- По каждому клиенту показываются имя или ФИО, тип, телефон, организация и процент скидки.
- Администратор может назначать целочисленный процент от 0 до 100. 0 снимает скидку. Подтверждение запроса клиента списывает выбранную скидку и сохраняет запись в истории.
- В банк включены как сохранённые профили, так и данные существующих заявок.
- API назначения скидок доступен только администраторам, подтверждённым на сервере.

## API
- GET /api/me: дополнительное поле `profile`.
- GET /api/profile: профиль авторизованного Telegram пользователя.
- POST /api/profile: `{name,phone,company,kind}`, скидка в теле запроса не допускается.
- GET /api/admin/profiles: список клиентов, только для администратора.
- POST /api/admin/profiles/discount: `{userId,discountPercent}`, только для администратора.

## Исходники
- `web/src/components/Profile/ProfilePage.tsx`: экран, редактор контактов, переходы к трекеру и бонусам.
- `web/src/components/Profile/profile.css`: стили отдельных элементов и анимация.
- `web/src/components/Profile/AdminClientProfiles.tsx`: фильтры и редактирование скидок.
- `web/src/components/Profile/admin-profiles.css`: стили административного банка.
- `internal/telegram/miniapp_profiles.go`: валидация, хранение и защита прав доступа.
- `internal/telegram/miniapp_profiles_test.go`: сохранение, права и начисление.
- `cmd/server/miniapp.go`: REST API.

## Безопасность и данные
Сервер проверяет подпись Telegram initData, а не принимает Telegram ID из клиентской формы. Клиенту запрещено менять процент скидки. Перезапуск сервера сохраняет данные; записи находятся в существующем `leads.json`. При эксплуатации требуется включать резервное копирование этого файла. Для текущих данных старых заявок отдельная миграция не нужна.
